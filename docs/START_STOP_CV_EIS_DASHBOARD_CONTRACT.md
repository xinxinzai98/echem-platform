# CV–EIS 分析页面契约

## 分析问题

哪些数据库材料同时具有可配对的正式 CV 与 EIS 测试；使用同材料、同阶段 EIS 的高频串联电阻后，其 CV 回扫曲线和目标电流密度过电位如何变化？

## 默认计算口径

- 原始数据始终保留且可与补偿结果对照。
- CV 主结果使用最后一次阴极转折后的回扫分支。
- CorrTest 电流密度与阻抗面积归一化单位分别使用 `A/cm²`、`Ω·cm²`。
- CHI 原始单位为 `A`、`Ω`；缺少几何面积时只显示电流曲线与 iR 校正，不报告电流密度过电位。
- 高频 `Rs` 使用 EIS 从最高频向低频搜索到的第一个 `Z''=0` 交点线性插值；不使用低频实部替代。
- 90% 离线补偿：`E_corr = E_meas - 0.90 × j × Rs`；绝对电流数据使用 `E_corr = E_meas - 0.90 × I × Rs`。
- 在 Hg/HgO、1 M KOH、25 °C 的既定实验口径下，`E_RHE = E_Hg/HgO + 0.9268 V`，HER 过电位为 `η = -1000 × E_RHE`。
- 目标电流密度默认提供 `10/50/100/200/300/500 mA/cm²`，仅在回扫实际覆盖目标时显示。

## 数据质量门槛

- CV 与 EIS 必须来自同一数据库材料目录；多文件时结合阶段名与时间邻近度配对。
- 默认排除二进制文件、诊断目录、`rejected_data`、明显 Cdl 扫速序列和复制件。
- 数据表头、数值列、单位、扫描转折、EIS 高频交点或仪器补偿状态任一无法确认时，不输出正式补偿过电位，并展示原因。
- CorrTest 压缩头中的 `IsIR=True` 视为仪器已补偿，禁止再次离线补偿。
- 页面不得把文件名中的电流、低频 EIS 点或其他材料的 `Rs` 当作计算依据。

## 图表契约

- 分析问题：所选材料的回扫 CV 在原始与 90% iR 补偿后如何变化？
- 图表家族：有序轴趋势图；具体形式为双线 CV 曲线。
- 横轴：`E vs RHE (V)`；纵轴：阴极电流密度 `j (mA/cm²)`，CHI 缺面积时改为 `I (mA)`。
- 原始曲线使用深灰虚线；iR 补偿曲线使用高对比蓝色实线，并使用线型而非仅颜色区分。
- 图题保持中性，副标题明确回扫、90% iR、`Rs`、参比换算和数据来源。
- 交互：单材料选择、目标电流密度切换、原始/补偿显示开关、框选缩放、复位和数据点提示。
- 数据量：单条正式 CV 通常数百至数千点；网页下采样上限 2,400 点并保留端点和目标电流交点。
- 空数据回退：无安全配对时显示质量原因表，不绘制误导曲线。

## 页面布局

1. 顶部指标：可识别 CV、可识别 EIS、同目录配对、可正式计算过电位、待人工补充。
2. 左侧材料列表：搜索、收藏优先、来源机、质量状态和 `Rs`。
3. 主图：原始与 iR 补偿后的 CV 回扫。
4. 过电位卡片：目标电流密度下 raw / 90%-iR 数值。
5. 证据与质量：CV/EIS 文件名、SHA-256、配对规则、单位、面积、`Rs` 提取方法与警告。

## 最终 QA

- 与至少一组已验证 CorrTest 金标数据复算 `Rs` 和过电位。
- 覆盖 CorrTest、CHI、缺 EIS、缺面积、无高频交点、仪器已补偿、多候选文件和恶意路径输入。
- 检查三个常用桌面宽度下的标签、图例、缩放、空状态和打印布局。
- API 只返回数据库逻辑路径与哈希，不返回 Windows 绝对路径或原始二进制内容。

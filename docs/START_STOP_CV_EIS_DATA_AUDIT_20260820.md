# Start–stop Studio CV–EIS 数据审计（2026-08-20）

## 数据集与粒度

- 数据源：Windows 主机 `192.168.110.225` 的独立 Start–stop SQLite 原始文件数据库，只读检查。
- 当前原始文件：1,271 个。
- 初步文件名识别：CV 178 个、EIS 120 个；同目录同时出现 CV/EIS 的目录 97 个，CV-only 目录 12 个，EIS-only 目录 4 个。
- 页面分析粒度：一个数据库材料目录中的一个正式 CV 测试阶段，以及与其配对的一份 EIS。

## 格式覆盖

- CorrTest：`CSStudioFile,ID_CV`，`E(V)`、`i(A/cm²)`；EIS 为 `Z'(Ohm.cm²)`、`Z''(Ohm.cm²)`。压缩头可读出面积和仪器 iR 开关。
- CHI760E：`Cyclic Voltammetry`，`Potential/V, Current/A`；EIS 为 `Freq/Hz, Z'/ohm, Z"/ohm`。当前文本没有可确认的几何面积。
- 北京数据列：主要为 CorrTest 文本，与上述面积归一化解析路径一致。

## 高价值质量检查

1. CV 与 EIS 仅在同一数据库材料目录内配对。
2. 多文件目录优先匹配去掉 `CV/EIS` 后相同的文件名前缀，例如 `16.1#-Fe30-CV` 只配 `16.1#-Fe30-EIS`。
3. `her-cv/her-eis`、`s2cv/s3eis`、`cvpre/eis` 和 `post cv/post ... eis` 使用明确阶段规则。
4. 高频 `Rs` 从最高频向低频搜索首个 `Z''=0` 交点；100 Hz 以下交点不作为串联电阻。
5. CorrTest 头若显示 `IsIR=True`，禁止再次离线 iR 补偿。
6. CHI 缺少面积时仅画 `mA` 曲线，不输出 `mA/cm²` 过电位。
7. API 只公开数据库逻辑路径和 SHA-256，不公开 Windows 原始绝对路径或原始文件内容。

## 使用边界

- 当前默认参比口径为 Hg/HgO、1 M KOH、25 °C，`E_RHE = E_Hg/HgO + 0.9268 V`。
- 这是一项明确显示在新页面上的计算假设；若某批数据使用不同参比、电解液或温度，需要另行配置，不能直接比较。
- 页面不会根据文件夹名中的电流值、低频 EIS 实部或其他材料的 `Rs` 补齐缺失信息。

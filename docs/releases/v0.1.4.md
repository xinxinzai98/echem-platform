# Echem Platform v0.1.4

> Draft release notes. Publish only after the pull request is merged, `main` CI is green, and the attached artifact checksum has been verified.

`v0.1.4` is the first formal public release of Echem Platform, a local-first, read-only workbench for indexing and visualizing selected CHI and CorrTest electrochemistry exports.

## Highlights

- Index local CHI and CorrTest export folders without modifying source files.
- Preview common two-dimensional CV, EIS, OCP, CA, and CP/GCD curves.
- Record a full SHA-256 fingerprint for every indexed source.
- Store research metadata and audit events in a separate local SQLite database.
- Run locally on Python 3.9 or newer with no third-party Python dependency.
- Reproduce the public baseline with four documented synthetic fixtures.

## Safety boundary

This release does not open serial ports, execute CHI macros, call a CorrTest SDK, control instrument software, listen on a non-loopback address, or upload laboratory data.

It is not an instrument interlock, emergency-stop system, backup system, or scientific-analysis authority. Review [KNOWN_LIMITATIONS.md](../../KNOWN_LIMITATIONS.md) and [SECURITY.md](../../SECURITY.md) before use.

## Install from the attached source ZIP

1. Download `echem-platform-v0.1.4.zip` and `echem-platform-v0.1.4.zip.sha256` from this Release.
2. Verify the ZIP's SHA-256.
3. Extract the archive.
4. Run `python3 app.py` or, on Windows, `py -3 app.py`.
5. Open `http://127.0.0.1:8787`.

The source ZIP does not bundle Python and is not a Windows installer. The repository's Windows launcher scripts require a separately built portable runtime.

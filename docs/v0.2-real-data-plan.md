# V0.2 真实数据只读接入计划

## 目标

在不访问仪器串口、不调用厂商控制接口、不修改原始实验文件的前提下，
用真实 CHI 与 CorrTest 导出文件验证解析准确性和持续扫描稳定性。

## 公开仓库边界

- 实际路径写入被 Git 忽略的 `config.local.json`
- 真实数据和精确盘点结果保留在被 Git 忽略的本机目录
- 公开测试样例必须先脱敏并经人工确认
- 厂商帮助文件、SDK、安装包和宏文件不进入公开仓库
- 厂商随软件提供的二进制示例不作为公开测试夹具

## 开发阶段

1. 配置分层与私有数据隔离
2. 解析器路由、标识和数据库迁移
3. CHI / CorrTest 文本解析器拆分与源文件可用性状态
4. 真实样例候选文件盘点
5. 经批准复制最小脱敏样例
6. 按仪器和方法增加解析器及回归测试
7. Windows 本机持续扫描验收

## 验收标准

- 所有源文件扫描前后大小、修改时间和 SHA-256 不变
- 正在写入的文件被暂缓处理
- 重复扫描不产生重复导入
- 每条记录包含解析器标识和版本
- 源文件移动或删除后显示不可用状态，但不删除缓存曲线和人工元数据
- 未识别文件进入可解释的异常状态，不导致平台退出
- 只监听 `127.0.0.1`
- `serial_access=false`
- `instrument_control=false`

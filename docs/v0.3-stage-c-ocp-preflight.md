# V0.3 阶段 C：60 秒 OCP 安全门

阶段 C 只为一次经过现场复核的 60 秒 OCP 建立最小实机闭环。代码包含 Windows
本机进程启动能力，但公开配置和默认部署始终关闭控制；本阶段不访问串口，也不允许
CV、LSV、EIS、多工步或任意命令执行。

## 默认状态

- `instrument_control_enabled=false`
- 服务只监听 `127.0.0.1`
- `/api/control/preflight` 只读可用
- 创建、确认、启动和停止请求接口在控制关闭时返回 404
- 不创建运行目录，不写宏，不启动 CHI

公开基础配置不能启用控制。只有被 Git 忽略的 `config.local.json` 可以显式启用，
而且必须同时提供 CHI 可执行文件哈希和已复核 OCP 参数指纹。

## 固定范围

阶段 C 运行协议必须同时满足：

1. 只有一个已启用工步；
2. 工步为 OCP；
3. `duration_s` 精确等于 60；
4. 执行参数指纹与本机配置的 `stage_c_ocp_profile_sha256` 一致；
5. 输出目录由服务端生成，且每次使用新的 `run_id`。

参数指纹只覆盖会进入宏的 OCP 参数，不覆盖样品编号、显示名称或保存文件名。它用于
防止复核后的参数被悄然改变，不代表这些参数本身已经获得实验授权。

只读检查一个候选协议：

```sh
python3 scripts/inspect_stage_c_protocol.py path/to/protocol.json
```

命令只返回是否符合范围和参数指纹，不写文件、不启动软件。

## 启用前的本机配置

复制 `config.stage-c.local.example.json` 为 `config.local.json`，先替换路径和两个
SHA-256，仍保持 `instrument_control_enabled=false`。打开
`http://127.0.0.1:8787/monitor`，确认预检能够正确识别：

- CHI 可执行文件和工作目录；
- 控制根目录与运行目录上级；
- CHI 可执行文件 SHA-256；
- OCP 参数指纹；
- 当前 CHI 实例数；
- 平台活动任务数。

只有现场条件满足且准备进行专门的阶段 C 验收时，才把本机覆盖配置改为：

```json
{
  "instrument_control_enabled": true,
  "control_stage": "ocp_60s"
}
```

公开 `config.json` 必须继续保持关闭。参数变更、可执行文件变更或平台重启都会使此前
的一次性确认失效。

## 启动链路

1. 从协议草稿创建不可变运行快照；
2. 写入新的运行目录：
   `protocol.json`、`protocol.normalized.json`、`protocol.mcr`、
   `manifest.json`、`events.jsonl`；
3. 重新校验快照、宏、CHI 可执行文件和参数指纹；
4. 操作者逐项完成现场确认并手工输入 `run_id`；
5. 服务只返回一次短期有效的确认令牌；
6. 点击启动时消费令牌，再次检查 CHI 实例数和文件冲突；
7. 使用参数数组和 `shell=False` 从 CHI 工作目录启动 `/runmacro`。

启动器不接受来自网页的可执行文件路径、工作目录、宏路径或任意命令行。

## 完成与恢复

页面只有同时读回以下证据时才显示“已确认完成”：

- CHI 子进程返回码为 0；
- `.bin` 和 `.txt` 均存在且大小、修改时间稳定；
- `.txt` 已被现有数据解析器解析；
- 扫描前后两个源文件的大小、修改时间和 SHA-256 完全一致。

实验完成与数据解析状态分别保存。文件齐全但解析失败时，运行可以结束，但页面只
显示“数据需复核”，不能显示“已确认完成”。

平台重启后会恢复运行记录和 PID 观察。如果重启导致子进程返回码不可读，平台把运行
标记为 `needs_review`，不会根据文件存在而猜测成功。所有尚未使用的确认令牌在重启
时失效。

## 停止边界

网页“停止”只记录请求，并提示操作者在 CHI 软件中停止和现场确认 `celloff`。阶段 C
不会调用 `kill`、`terminate` 或 `Stop-Process` 结束 CHI。Windows 正常停止平台的脚本
也会在存在活动仪器任务时拒绝关闭平台。

## 实机验收门

合并或部署代码不等于实机验收完成。首次真实运行前仍必须确认：

- Windows 当前没有其他 CHI 实例或实验；
- 参比、工作和对电极接线正确；
- 电解液、浸没、通风和现场停止手段正常；
- OCP 参数指纹来自已经实机验证并经负责人复核的参数；
- 操作者在设备电脑旁全程观察。

实机验收记录必须包含进程 PID、返回码、两份输出哈希、解析状态和扫描前后不变证明。
